# Addresses API

Customer and admin address management endpoints.

**Total Endpoints:** 5

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/v1/addresses` | List the current user's addresses |
| `GET` | `/api/v1/addresses/{id}` | Get an address by ID |
| `POST` | `/api/v1/addresses` | Create a new address |
| `PUT` | `/api/v1/addresses/{id}` | Update an address |
| `DELETE` | `/api/v1/addresses/{id}` | Delete an address |
