# Product Variants API

Product variant management endpoints.

**Total Endpoints:** 6

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/v1/product-variants/product/{productId}` | Get variants for a product |
| `GET` | `/api/v1/product-variants/{id}` | Get a variant by ID |
| `POST` | `/api/v1/product-variants` | Create a product variant |
| `PUT` | `/api/v1/product-variants/{id}` | Update a product variant |
| `DELETE` | `/api/v1/product-variants/{id}` | Delete a product variant |
| `GET` | `/api/v1/product-variants/{id}/sku/{sku}` | Get a variant by SKU |
