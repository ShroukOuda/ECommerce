# Returns API

Return request endpoints for administrators.

**Total Endpoints:** 3

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/v1/admin/returns` | Get return requests for the current user |
| `GET` | `/api/v1/admin/returns/{id}` | Get a return request by ID |
| `POST` | `/api/v1/admin/returns/create` | Create a return request |
