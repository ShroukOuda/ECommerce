# Shipping API

Customer shipping lookup endpoints.

**Total Endpoints:** 3

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/v1/shipping` | Get the current user's shipping records |
| `GET` | `/api/v1/shipping/{id}` | Get a shipping record by ID |
| `GET` | `/api/v1/shipping/order/{orderId}` | Get shipping records by order ID |
